# 스피드서원 — 전국 지역 배관 웹사이트

전국 17개 시·도 / 229개 시·군·구 / 2,819개 행정동을 다루는 정적 사이트입니다.
`_build/` 의 생성기가 저장소 루트에 HTML을 출력합니다.

배포: **https://speedseowon.netlify.app/** (Netlify, `netlify.toml` 로 루트 발행)

```
python3 _build/build.py      # 248개 페이지 + sitemap + robots.txt 생성
python3 tools/make_images.py # 이미지 슬롯 생성/갱신 (WebP 30KB 이하)
```

## 1. 구조

```
/                                   메인
/area/                              지역 허브 — 시·도 17개 아코디언
/area/<시도>/                       시·도 페이지 17개 — 관할 시·군·구 전체 + 행정동 펼치기
/area/<시도>/<시군구>/              시·군·구 페이지 229개 — 지역 고유 콘텐츠
sitemap.xml → sitemap-core.xml / sitemap-area.xml
robots.txt
assets/css/site.css                 디자인 시스템 (단일 파일)
img/*.webp                          이미지 (전부 30KB 이하)
```

### 드릴다운 동선

`서울 클릭 → 25개 자치구 전부 노출 → 구 클릭 → 그 구의 행정동 전부 노출`

두 경로로 모두 됩니다.

- **인라인**: 시·도 페이지에서 구를 누르면 `<details>` 가 열리며 행정동이 그 자리에 펼쳐집니다.
- **전용 페이지**: 같은 블록의 버튼으로 시·군·구 상세 페이지로 이동합니다.

`상계1동 ~ 상계10동` 처럼 숫자로만 갈린 행정동은 **대표 1곳(`상계동`)으로 통합**했습니다.
통합 로직은 `_build/site/regions.py` 의 `_dedupe_dongs()` 입니다.

## 2. 얇은 콘텐츠 방지

지역 페이지를 지역명만 바꾼 복제본으로 만들면 사이트 전체가 저품질 판정을 받습니다.
그래서 229개 시·군·구마다 **그 지역에만 해당하는 사실 7가지**를 데이터로 넣었습니다.

| 필드 | 내용 | 예 (강남구) |
|---|---|---|
| `era` | 준공 시기 특성 | 1978~1983년 개포·대치 대단지 + 2015년 이후 재건축 |
| `stock` | 주택 유형 구성 | 아파트 최상위권, 역삼·삼성 업무용 오피스텔 밀도 |
| `terrain` | 지형·배수 여건 | 탄천·양재천 저지대 / 구룡산·대모산 고지대 |
| `biz` | 상권·시설 | 테헤란로 오피스, 압구정·청담 요식업, 대치 학원가 |
| `note` | **그 지역 고유 배관 관찰** | 재건축 전 단지 적수 문의와 신축 오피스텔 봉수 증발이 동시 유입 |
| `spots` | 주요 출동 구역 | 역삼동 오피스 상권, 압구정 로데오 … |
| `mix` | 증상 구성 비율 | 배관막힘 31 / 누수탐지 27 / 수전·변기 22 |

`_build/site/content.py` 가 이 값들을 읽어 문단을 조립하고, 문장 골격도 slug 해시로
3갈래씩 분기시켜 같은 틀이 반복되지 않게 했습니다.

**검증 결과** — 229개 페이지 본문 완전중복 **0건**, `note` 중복 **0건**,
페이지당 본문 **3,151~3,553자**.

`_build/site/config.py` 한 파일에 모여 있습니다.

| 항목 | 현재 값 | 상태 |
|---|---|---|
| 전화번호 | `010-5183-4300` | ✅ 실제 번호 반영됨 |
| 도메인 | `speedseowon.netlify.app` | ✅ 반영됨 (`netlify.toml` 포함) |
| 사업자등록번호 | `000-00-00000` | ⚠️ 실제 번호로 |
| 기계설비공사업 등록번호 | `제0000호` | ⚠️ 실제 번호로 |
| 주소 | `수원시 팔달구 ○○로 00` | ⚠️ 실제 주소로 |

### 통계 수치 — 가장 중요

아래 값은 **아직 실제 데이터가 아닙니다.** 허위 기재는 신뢰도와 법적 리스크가 있고,
구글 스팸 정책에도 걸립니다. 발행 전에 실제 출동 기록으로 바꿔 주세요.

- `config.py` 의 `STAT_TOTAL_CASES` / `STAT_PRICE_BASE` / `STAT_ARRIVE_MIN`
- 각 시·군·구의 `mix`(증상 구성 비율) 와 `arrive`(평균 도착 분)
  → `_build/site/data_*.py`

지역별 `era` / `stock` / `terrain` / `biz` / `note` 는 공개된 지역 정보와
배관 실무를 바탕으로 작성했습니다. 대표님 현장 경험과 대조해 보완하시면
E-E-A-T 신호가 더 강해집니다.

## 4. 롱테일 내부링크

메인·지역 허브·시·도 17개·시·군·구 229개 **전 페이지**에 상황별 주제 묶음을 넣었습니다.
`_build/site/longtail.py` 가 생성합니다.

| 묶음 | 링크 대상 |
|---|---|
| 비용이 먼저 궁금할 때 | `/price/*` |
| 밤이거나 주말일 때 | `/contact/`, `/price/night-surcharge/`, `/guide/winter-freeze/` |
| 증상만 있고 원인을 모를 때 | `/guide/*` |
| 직접 해볼 수 있는 범위 | `/guide/*`, `/service/faucet/`, `/service/toilet-parts/` |
| 건물 유형별로 다른 점 | `/service/apartment/`, `/case/villa/`, `/service/commercial/` |

**지역×서비스 조합 페이지를 새로 만들지 않고**, 기존 문서로 문맥형 앵커를 보내는 방식입니다.
229 × 27 = 6,183페이지를 찍어내면 도어웨이로 걸립니다.

앵커텍스트는 지역명과 slug 해시로 3갈래씩 변형됩니다.

> 강남구 → "강남구 물 새는 곳 찾는 비용"
> 노원구 → "노원구 누수탐지 비용과 탐지 방식"
> 해운대구 → "해운대구 누수 위치 확인 견적"

**검증** — 강남구 페이지 기준 본문 내부링크 **57개(고유 40개)**, 동일 앵커 2회 이상 반복 **0종**.

## 5. 구조화 데이터 (스키마)

248개 **전 페이지**에 적용했습니다.

| 스키마 | 적용 |
|---|---|
| `Plumber` (LocalBusiness) | 전 페이지 — `aggregateRating` + `review` 포함 |
| `AggregateRating` | 전 페이지 (4.7 / 14건, 후기 목록에서 자동 계산) |
| `Review` | 전 페이지 3건씩, 지역이 맞으면 그 지역 후기 우선 |
| `BreadcrumbList` | 전 하위 페이지 |
| `FAQPage` | 메인 + 시·군·구 229개 (지역 맞춤 5문항) |
| `Service` + `OfferCatalog` | 시·군·구 229개, `areaServed` 포함 |
| `ItemList` | 지역 허브 + 시·도 17개 |
| `WebSite` | 메인 |

`Plumber` 노드는 페이지당 하나만 나가고 평점·후기가 그 안에 합쳐집니다.
(`@id` 가 같은 노드를 두 번 내보내면 파서가 어느 쪽을 쓸지 모호해집니다)

### ⚠️ 후기는 반드시 실제 수집분으로

`_build/site/data_reviews.py` 의 14건은 **형식을 보여주기 위한 표본**입니다.
없는 리뷰·별점을 스키마로 넣으면 구글 리치 결과 제재 대상입니다.

- 평점은 후기 목록에서 **자동 계산**됩니다. 숫자를 임의로 적는 경로 자체를 만들지 않았습니다.
- 스키마에 들어가는 후기는 **화면에도 그대로 렌더링**됩니다. 구글이 요구하는 조건입니다.
- 네이버·구글 리뷰에서 옮길 때 작성자 표기는 동의 범위 안에서 정하세요.

### 실제 작업사진으로 교체

이 작업 환경은 네트워크 정책상 `drive.google.com` 접근이 차단돼 있어
구글드라이브 원본(21장)을 내려받지 못했습니다. 현재 슬롯에는 같은 파일명·같은 비율의
브랜드 플레이트가 들어가 있습니다.

**차단되지 않은 PC에서 아래 한 줄이면 전부 실제 사진으로 바뀝니다.** HTML은 손댈 필요 없습니다.

```bash
bash tools/import-drive-photos.sh
```

동작: 드라이브 폴더 → `tools/raw/` 다운로드 → 슬롯 비율로 중앙 크롭 →
WebP 30KB 이하로 압축 → `img/` 에 같은 이름으로 덮어쓰기.

어떤 사진을 어느 자리에 넣을지는 `tools/make_images.py` 의 `SLOTS` 순서로 조정합니다.
파일명과 `alt` 텍스트에는 이미 지역·서비스 키워드가 들어가 있습니다.

## 7. 디자인 시스템

`assets/css/site.css` 단일 파일. 외부 UI 프레임워크를 쓰지 않습니다.

- **시인성** — 본문 `#16202B` (흰 배경 대비 16.1:1), 보조 `#38495A` (8.6:1),
  캡션 `#526478` (5.5:1). 흰 배경에 쓰는 텍스트 색은 전부 WCAG AA 이상입니다.
  포커스 링은 앰버 3px + 외곽 그림자 2겹이라 밝은 배경/어두운 배경 양쪽에서 보입니다.
- **가독성** — 본문 17px / 행간 1.78, 산문 폭 `70ch` 제한, `word-break:keep-all`
  로 한글 단어가 중간에서 끊기지 않습니다. 제목은 `text-wrap:balance`.
- **UI/UX** — 탭 타깃 최소 48px, 모바일 하단 고정 통화 CTA,
  지역 아코디언은 `<details>` 기반이라 JS 없이도 동작(INP 부담 최소).
- **모바일 플로팅 전화 버튼** — 우측 하단 오렌지 원형 버튼(62px). 전 페이지 노출.
  터치하면 `tel:` 로 바로 연결됩니다. 신호 링이 퍼지는 애니메이션 + 수화기 흔들림 +
  상하 부유 3종이 겹쳐 눈에 띄게 했고, `prefers-reduced-motion` 에서는 버튼은 남기고
  움직임만 멈춥니다. 하단 CTA 바와 겹치지 않도록 `bottom:82px` 에 배치했습니다.
- **반응형** — 1180 / 1024 / 880 / 660 / 560px 브레이크포인트.
  360px에서 가로 스크롤 없음을 확인했습니다.
- **접근성** — `prefers-reduced-motion`, `prefers-contrast:more`, 인쇄 스타일 대응.

## 8. SEO

- 구조화 데이터: `Plumber` / `WebSite` / `BreadcrumbList` / `FAQPage` /
  `Service`+`OfferCatalog` / `ItemList`
- 페이지마다 고유 `title` · `meta description` · `canonical` · `og:image`
- 사이트맵 분리(`core` / `area`), `robots.txt` 에 파라미터 URL 차단
- 내부링크: 시·군·구 페이지마다 시·도 부모 1 + 형제 지역 8 + 서비스 8 + 가이드 5 + 비용 5
- 외부링크: 지역별 관할 상수도사업본부 + 정부·협회 6곳 (`rel="noopener"`)
- 이미지: 파일명·alt에 지역/서비스 키워드, 히어로만 `fetchpriority="high"`,
  나머지 `loading="lazy"`, 전부 `width`/`height` 명시(CLS 방지)

**지역 × 서비스 조합 페이지는 만들지 않았습니다.** 229 × 27 = 6,183페이지가 되고
구글 스팸 정책의 "대량 저가치 콘텐츠 양산"에 정확히 걸립니다.
시·군·구 페이지 안에서 서비스 페이지로 링크를 보내는 구조입니다.

## 9. 아직 안 만든 페이지

지역 축은 전부 완성됐고, 아래는 링크만 걸려 있는 상태입니다.

`/service/*` · `/price/*` · `/case/*` · `/guide/*` · `/about/*` ·
`/review/` · `/contact/` · `/privacy/` · `/terms/`

SEO 설계서 §8의 권장 순서에 따라 서비스 → 비용 → 가이드 → 사례 순으로
붙이면 됩니다. 생성기 구조는 그대로 재사용할 수 있습니다.
